一、起始页概览

新标签页被替换为 GG Bookmark 起始页，整体布局：

  • 顶部左侧：「所有书签」按钮（最左）与分类标签（导航精品 / 投资 / 系统…），可自定义。
  • 顶部中央：搜索框，点击左侧图标可切换搜索引擎，回车搜索。
  • 顶部右侧：帮助、显示设置、整理书签、设置、卡片添加。
  • 主体：按分类以网格卡片展示书签，卡片可多列、可拖动调整。

首次使用没有任何卡片，点击右上角「卡片添加」，或在空白处右键 → 新建卡片，选择一个书签文件夹即可生成。

二、卡片操作

  • 拖动调整顺序：按住卡片顶部的圆点手柄拖动，可调整卡片在列内的上下顺序，也可拖到其它列。
  • 调整卡片高度：拖动卡片底部横条可上下调整该卡片的高度。
  • 列宽：所有卡片列宽在「设置 → 卡片列宽」统一调整。
  • 点击书签：在新标签页打开该网站。
  • Ctrl / ⌘ + 点击 或 鼠标中键：在后台新标签页打开，页面停留在当前起始页。
  • 拖动书签：卡片内拖动可排序；拖到另一张卡片可把书签移动到那个文件夹。
  • 右键书签：打开 / 复制链接 / 移出卡片 / 删除书签。

三、所有书签浮窗

点击顶部最左侧的「所有书签」按钮，或在页面任意处按下 ~ / ` 键，即可打开一个居中的书签浏览器浮窗，方便在全部书签中快速找到并打开任意一个。

  • 左侧导航树：按文件夹层级浏览，点文件夹行选中，点箭头折叠 / 展开。
  • 右侧内容区：显示当前文件夹的书签；勾选「含子文件夹」可连同子文件夹分组展示。
  • 即时搜索：输入即过滤，支持多词空格匹配，匹配标题 / 链接，关键词高亮并显示所在路径。
  • 键盘流：打开后自动聚焦搜索框，↑ / ↓ 选择，Enter 打开，Ctrl + Enter 或鼠标中键后台打开，Esc 先清空搜索词再关闭。
  • 后台打开：Ctrl / ⌘ + 点击或鼠标中键，在后台打开且浮窗不关闭，可连续打开多个书签。
  • 关闭：按 ~ / `、Esc，点右上角 ✕ 或点击浮窗外部。

四、卡片菜单

点击每张卡片右上角的设置按钮，可对单张卡片操作：

  • 重新选择文件夹：更换卡片绑定的书签文件夹。
  • 包含子文件夹：开关，开启后连同子文件夹里的书签一起显示。
  • 自适应高度 / 固定高度：单张卡片的展开方式。
  • 紧凑模式：自动 / 开启 / 关闭。
  • 重命名：修改卡片标题（同时会重命名原书签文件夹）。
  • 删除卡片：仅移除卡片，不删除书签。

五、紧凑模式与卡片高度

  • 紧凑模式：当卡片高度较小时，书签项自动把「标题 + 域名」合并到一行、图标变小，节省空间。
  • 全局设置：点击顶部「显示设置」按钮，可一次性对所有卡片设置紧凑模式（自动 / 固定开启 / 固定关闭）和卡片高度（自适应 / 固定）。
  • 单卡覆盖：每张卡片右上角也有独立的紧凑 / 自适应切换，可单独覆盖全局设置。

六、分类

  • 切换分类：点击顶部标签。
  • 新建分类：点击分类栏最右侧的「＋」。
  • 重命名 / 删除：右键分类标签。
  • 每个分类拥有独立的卡片布局与顺序。

七、整理书签

点击顶部「整理书签」按钮进入，是一个分栏式的书签管理器：

  • 左侧：文件夹树。
  • 右侧：文件夹内容面板，可打开多个面板并排对比。
  • 多选：Ctrl / ⌘ 单击，或 Shift 范围选择。
  • 移动 / 排序：拖动选中项到其它文件夹移动；同文件夹内拖动排序。
  • 操作：新建文件夹、重命名、删除、移动，均支持撤销（Ctrl / ⌘ + Z 或顶部按钮）。

八、设置

点击顶部「设置」按钮打开右侧设置面板：

  • 背景：渐变 / 深色渐变 / 预设壁纸 / 自定义图片，可调模糊与遮罩透明度。
  • 搜索：默认搜索引擎。
  • 外观：主题（黑暗 / 明亮）、主题色、卡片列宽、字体大小、书签图标来源、是否显示域名。
  • 书签图标来源：FaviconSnap / DuckDuckGo / Google / 本地首字母；图标获取成功后自动缓存，超时则显示首字母。

九、数据导入 / 导出 / 同步

  • 导出配置：把设置、卡片布局连同书签导出为 JSON 文件备份。
  • 导入配置：从 JSON 恢复（书签会重建，建议先备份）。
  • 清除配置：恢复默认并删除本地配置（不会删除浏览器书签）。
  • 同步：支持 WebDAV 服务器同步，可手动上传 / 下载，或按间隔、设置变更、书签变更自动触发。

十、常用技巧

  • 按 ~ / ` 键可随时唤起「所有书签」浮窗，输入关键词即可快速定位并打开。
  • 拖动卡片到列的空位再松开，即可快速换列。
  • 紧凑模式下卡片能装下更多书签，适合窄屏。
  • 「自动适应」按钮让卡片按子项数量自动展开全部内容。
  • 右键空白处可直接在当前列新建卡片。
